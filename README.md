# ふるさと納税 上限額シミュレーター

住宅ローン控除・ワンストップ特例／確定申告の違いまで反映して、ふるさと納税の控除上限額と実質負担を計算する静的サイトです。

公開URL: https://fukicycle.github.io/furusato/

## 特長

- 2026年（令和8年）分の税制に対応（所得税の基礎控除 最大104万円、給与所得控除の最低額74万円、特例控除割合の判定方法の見直しなど）
- 住宅ローン控除がある場合に、確定申告で住宅ローン控除が目減りする分を計算し、ワンストップ特例との実質負担を比較
- 寄附額ごとの実質負担をグラフで表示
- 計算はすべてブラウザ内で完結（入力内容は送信・保存しない）
- スマホファースト／グラスモーフィズムのUI、ライト・ダークモード対応

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 計算ロジックの単体テスト
npm run build      # dist/ に出力
```

## 構成

| パス | 内容 |
|---|---|
| `src/tax/params.ts` | 年分ごとの税制パラメータ（改正時はここを追加・差し替え） |
| `src/tax/engine.ts` | 所得税・住民税（所得割）の計算 |
| `src/tax/limit.ts` | 上限額の探索、実質負担の計算 |
| `src/ui/` | グラフ、表示用フォーマット |
| `index.html` | 画面と解説コンテンツ（SEO用の構造化データを含む） |
| `docs/furusato-nozei-research.md` | 制度の調査メモ |

### 上限額の考え方

- **上限目安**: 住民税の特例分が「所得割額（調整控除後）の20%」に達する寄附額、または住民税が足りず控除しきれなくなる寄附額
- **実質負担**: 寄附額 −（寄附しなかった場合の税額 − 寄附した場合の税額）。住宅ローン控除の目減りも含めて計算
- 上限探索は端数処理なしの連続値で行い、表示用の内訳は実際の端数処理（千円未満・百円未満切捨て等）で計算

## デプロイ

`main` ブランチへの push で GitHub Actions がビルドし、GitHub Pages に公開します。
初回はリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。

## SEO

- タイトル・description・canonical・OGP・Twitterカード
- 構造化データ（`WebApplication`、`FAQPage`）
- 解説記事・FAQを静的HTMLで配置
- `sitemap.xml`（Google Search Console から送信してください。プロジェクトサイトのため `robots.txt` はドメイン直下に置けません）

## 免責

計算結果は目安であり、実際の税額を保証するものではありません。
